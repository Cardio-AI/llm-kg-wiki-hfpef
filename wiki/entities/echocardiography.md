# Echocardiography

> Transthoracic ultrasound-based cardiac imaging; the first-line modality for LVEF measurement, diastolic function assessment, and structural evaluation in HFpEF diagnosis.

---

## Description

Echocardiography uses ultrasound to generate real-time cardiac images. Standard transthoracic echocardiography (TTE) provides assessment of:
- **Systolic function:** LVEF (biplane Simpson's or 3D), wall motion abnormalities, global longitudinal strain (GLS)
- **Diastolic function:** E/e' ratio, LA volume index, TR velocity, deceleration time
- **Structure:** LV mass index, relative wall thickness, LA size, valvular morphology and function
- **Haemodynamics:** Estimated pulmonary artery pressures (from TR velocity), inferior vena cava collapsibility

Transoesophageal echocardiography (TOE) provides higher-resolution imaging when TTE windows are inadequate. Stress echocardiography allows assessment of exercise-induced filling pressure elevation. (source: 2021-ESC-Guidelines-Heart-Failure.pdf)

## Role in HFpEF

Echocardiography is the **primary diagnostic tool for HFpEF**, used to:

1. Measure LVEF to confirm ≥50% (criterion 2 of the three-criterion diagnostic approach)
2. Assess [[diastolic-dysfunction]] markers (E/e', LA volume index, TR velocity, LV mass) — criterion 3
3. Exclude alternative diagnoses (valvular disease, HCM, pericardial disease, amyloid)
4. Estimate PA pressure for pulmonary hypertension assessment
5. Perform diastolic stress testing (exercise echocardiography) in equivocal cases

Key markers from ESC 2021 Table 9:

| Parameter | HFpEF threshold |
|---|---|
| E/e' ratio | >9 (sens 78%, spec 59%); >13 (sens 46%, spec 86%) |
| LA volume index | >34 mL/m² (SR), >40 mL/m² ([[atrial-fibrillation\|AF]]) |
| LV mass index | ≥95 g/m² (F), ≥115 g/m² (M) |
| TR velocity | >2.8 m/s |
| LV GLS (stress echo) | <16% (sens 62%, spec 56%) |

(source: 2021-ESC-Guidelines-Heart-Failure.pdf)

## Evidence

**Benefits in HFpEF:**
- Widely available, no radiation, real-time assessment
- Can assess filling pressures non-invasively (E/e')
- Enables diastolic stress testing without invasive catheterisation
- Monitors structural changes over time (LA size, LV mass)

**Drawbacks in HFpEF:**
- Inter-observer variability in LVEF measurement (~5–10% absolute) can shift patients between phenotype categories
- Acoustic window limitations (obesity, COPD) reduce image quality
- E/e' ratio has only moderate diagnostic accuracy for elevated filling pressures (specificity only 59% at threshold >9)
- Cannot directly measure PCWP or LVEDP — invasive confirmation remains gold standard

(source: 2021-ESC-Guidelines-Heart-Failure.pdf)

## Status

**ESC 2021:** Recommended as the primary imaging modality in the HF diagnostic pathway. Stress echocardiography (diastolic stress test) is Class IIb for equivocal HFpEF cases. (source: 2021-ESC-Guidelines-Heart-Failure.pdf)
