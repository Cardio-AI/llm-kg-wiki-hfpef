# ACC/AHA Heart Failure Guidelines

> The 2022 ACC/AHA/HFSA guideline established SGLT2 inhibitors as the first pharmacological therapy with Class 2a recommendation for HFpEF; the 2024 performance measure update formalized BP control as HFpEF's first dedicated performance measure.

## 2022 ACC/AHA/HFSA Guideline — HFpEF-Specific Recommendations

### Class 2a (Should Be Considered)
- **SGLT2 inhibitors** (dapagliflozin or empagliflozin): to reduce HF hospitalisation and CV mortality in HFpEF (LVEF ≥50%)
- **Blood pressure control** targeting <130/80 mmHg
- **Diuretics** for symptom relief (unchanged from prior)

### Key Milestones vs. Prior Guidelines
- First guideline with an evidence-based pharmacotherapy above Class 2b for HFpEF
- Reflected EMPEROR-Preserved and DELIVER trial data
- ESC 2023 update subsequently upgraded SGLT2i to Class 1 for HFpEF (European counterpart, see [[mcdonagh2021esc]])
(source: [[heidenreich2022aha]])

## 2024 Performance Measure Update (Kittleson 2024)

### New Performance Measures (Class 1)
| PM | Specification | HFpEF Relevance |
|---|---|---|
| **PM-2: BP Control in HFpEF with HTN** | SBP <130 + DBP <80 mmHg | **First HFpEF-dedicated performance measure** |
| PM-1: GDMT at discharge (HFrEF) | Multiple drug classes | HFrEF only |
| PM-3: SGLT2i for HFrEF | LVEF ≤40% | HFrEF only |

### New Quality Measures Relevant to HFpEF
| QM | Specification |
|---|---|
| **QM-1: SGLT2i for HFmrEF/HFpEF** | Quality (not performance) measure; LVEF >40% |
| QM-2: SDOH Screening | All HF patients; addresses disparities (see [[hfpef-disparities]]) |
| QM-6: Amyloid Screening (ATTR) | Monoclonal protein screen when bone scintigraphy performed for ATTR-CM |

(source: [[kittleson2024accaha]])

## ESC Guidelines (European Counterpart)

- **ESC 2021** (McDonagh 2021): First European guideline with HFpEF-specific content; SGLT2i not yet included
- **ESC 2023 update** (McDonagh 2023): SGLT2i upgraded to **Class 1** for HFpEF — more aggressive than ACC/AHA 2022
- See [[mcdonagh2021esc]], [[mcdonagh2023escupdate]]

## Evolution of HFpEF Recommendations

| Year | Guideline | Key HFpEF Milestone |
|------|----------|---------------------|
| 2013 | ACC/AHA | No pharmacotherapy recommendations for HFpEF |
| 2016 | ACC/AHA | Spironolactone Class 2b (based on TOPCAT) |
| 2021 | ESC | First HFpEF-specific European content |
| 2022 | ACC/AHA/HFSA | SGLT2i Class 2a — first pharmacotherapy above 2b |
| 2023 | ESC update | SGLT2i Class 1 for HFpEF |
| 2024 | ACC/AHA PM update | First HFpEF performance measure (BP control) |
