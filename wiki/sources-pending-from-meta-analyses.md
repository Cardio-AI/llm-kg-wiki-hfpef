|---|---|---|---|---|

> Note: Kitzman 2016 is the SECRET diet/exercise study (NCT01547182 or related). A specific source page for the diet + exercise arm would complement the [[supervised-exercise-training]] entity.

## How to Ingest a Candidate

1. Obtain the PDF and place in `raw/`
2. Read the PDF and assign a citekey (format: `AuthorYearKeyword`)
3. Create `wiki/sources/<citekey>.md` (study or source template)
4. If a named trial: create `wiki/entities/<trial-name>.md` (entity template)
5. Add to `wiki/trials.md` if a clinical trial; add to `wiki/citations.md`
6. Link from relevant entity/concept pages
7. Remove from this file
8. Update `wiki/log.md`
