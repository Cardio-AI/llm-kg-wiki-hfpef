Purpose: compare studies/guidelines/trials/mechanisms.

Outputs: `wiki/comparisons/`

---

# Rules

1. Resolve aliases first
2. Compare canonical pages only (see CLAUDE.md Governance Terms — `wiki/concepts/`, `wiki/entities/`, `wiki/sources/`), not derived artifacts
3. Focus on meaningful differences — differences that would change a clinical decision or contradict a claim elsewhere in the wiki, not incidental wording differences
4. Preserve methodological distinctions
5. Link densely with `[[wiki-links]]`, same as other tasks

---

# Structure

For each item being compared, use the trial/guideline structure below when comparing studies, trials, or guidelines (i.e. anything with a Population/Intervention/Outcomes design); use the mechanism structure when comparing concepts/mechanisms that don't have a PICO structure.

**Trial/guideline structure** — for each item:
- Short, concise 1-3 sentence summary
- Population
- Intervention
- Outcomes
- Key findings
- Strengths
- Weaknesses

**Mechanism structure** — for each item:
- Short, concise 1-3 sentence summary
- Definition
- Proposed pathway
- Supporting evidence
- Strengths
- Weaknesses

Then, regardless of which structure was used above:
- Similarities
- Differences
- Contradictions
- Clinical implications

---

# Output Naming

`wiki/comparisons/<topic-a>-vs-<topic-b>.md`, kebab-case, using the canonical page names being compared.
